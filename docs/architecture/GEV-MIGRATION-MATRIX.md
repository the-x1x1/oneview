# GEV → WORLDVIEW Migration Matrix

Audit of the God's Eye View (GEV) repository at base commit
`0dbde1e36c0177b7664b47702d77ba50f11ddadc` (main, 2026-09-20), imported 2026-09-21.
Companion document: [GEV-AUDIT-NOTES.md](./GEV-AUDIT-NOTES.md) (code-level reuse
notes). Provenance: [/UPSTREAM.md](../../UPSTREAM.md).

Repository facts used for this matrix: 1,026 files under `src/` (~269K lines
including bundled JSON/tests; ~156K lines of runtime JS), 328 `*.test.mjs` files run
under `node:test` (Node 24.14 / 26), Cesium 1.138.0, satellite.js 6.0.2, Vite 6,
no TypeScript, no UI framework. Server side is Vite dev-server middleware
(`server/providers/*`), not a standalone service.

## Decision vocabulary

| Decision    | Meaning                                                                                               |
| ----------- | ----------------------------------------------------------------------------------------------------- |
| **KEEP**    | Copy near-verbatim (rename/imports only). Pure modules with tests.                                    |
| **ADAPT**   | Reuse the logic behind a typed adapter; restructure ownership, remove DOM/window/Google coupling.     |
| **WRAP**    | Keep as an optional plugin behind a feature flag / adapter interface; not part of the baseline build. |
| **REPLACE** | Re-implement in WORLDVIEW (React/TS/Electron IPC); GEV code serves as spec only.                      |
| **REMOVE**  | Not carried over (out of Release 1 scope, licence, privacy or product decision).                      |
| **DEFER**   | Keep in the import but not in the baseline build; decide later.                                       |

Target packages use the WORLDVIEW names: world-model, provider-sdk, provider-runtime,
source-health, identity, hot-spatial-index, state-engine, query-engine, event-engine,
history-store, offline, render-core, render-cesium, render-maplibre, render-dense,
camera-gateway, diagnostics, updater, config, ui, core, runtime, ipc-contract,
apps/desktop, providers/_, tools/_, fixtures/\*.

Test-coverage column: **U** = node:test unit tests exist for that module group,
**S** = only source-text regression tests (tests that `readFileSync` the module and
assert on strings; brittle across a port), **B** = browser/puppeteer QA harness only
(`scripts/qa-*.mjs`, not run in CI), **–** = none found.

## Row notes and justifications

- **Rows 5, 8 (Google 3D is not foundational).** GEV's scene startup tries Google direct, then ion-hosted Google, and only then the keyless globe (`loadPhotorealisticTileset` in `src/maps/google3d.js`, called from `src/app/scene.js`). The `MapSourceController` itself is provider-agnostic; only `createDefaultMapSources` and `MapStackController` hard-wire `photoreal` as the default/unknown/recovery id. WORLDVIEW inverts this: the registry default is the keyless imagery+terrain stack and `google-3d` is an optional registered source. Several layer modules carry photoreal-specific branches (`src/layers/submarineCables/surface.js`, `src/services/meshFloorSampler.js`, `src/layers/cctv/ground.js`); those branches stay behind the adapter's "globe hidden" regime flag.
- **Row 12 (credits).** GEV renders attribution through Cesium's credit display. MapLibre has its own `AttributionControl`; render-core must own an attribution model that both renderers project, which is why the data moves to provider manifests.
- **Row 22–23 (aircraft).** `src/layers/flights` and `src/layers/military` are near-duplicates (records, ingestion, motion, tracking, rendering, snapshotRenderer, state, queries, lifecycle, policy, testing) differing mainly in source and colour. WORLDVIEW should build one aircraft pipeline from the portable pieces (`FlightRecords`, `MilitaryFlightRecords`, `createIngestion`, `motionModel`, `aircraftClass`) and treat "military" as an identity classification (the two families total ~12.6K lines of JS).
- **Row 33 (ALPR).** Removed as a product/privacy decision even though the data licence (ODbL) is permissive.
- **Row 35, 39, 83 (non-commercial data).** TeleGeography (CC BY-NC-SA 3.0) and Vantor/GeoPera (CC BY-NC 4.0) must not be in the commercial baseline. GEV's own LICENSE says deleting the event asset folder is not enough because `src/data/bhoteKoshiFloodPath.js` compiles the CC BY-NC coordinates into the bundle.
- **Row 46 (OpenSky).** DATA_SOURCES.md: "Its license is non-commercial, and operational use of the REST API in a live product can require a prior written agreement with OpenSky". Import the provider, ship it disabled, document the agreement requirement.
- **Row 48 (adsbdb).** DATA_SOURCES.md quotes adsbdb: route data "may not be copied, published, or incorporated into other databases without the explicit permission of David J Taylor". Type/registration lookups are less encumbered but the service publishes no licence; treat as verify.
- **Row 57 (Google News).** DATA_SOURCES.md: Google News terms "restrict use to personal, noncommercial use". Removed; Open-Meteo (CC BY 4.0 with link attribution) is retained as providers/weather.
- **Row 61–62, 64, 67 (voice, director, cockpit).** All depend on OpenAI Realtime or exist for cinematic/promotional use; none contributes to world-state. `src/voice/actionSchemas.js` remains useful as a catalogue of verbs when designing ipc-contract.
- **Row 65 (UI).** GEV's UI is vanilla DOM with `<!-- gev:template … -->` expansion; there is no component model to port. What is worth keeping are the _behaviour contracts_ (panel disclosure, Escape handling, keyboard focus order) captured in `docs/CURRENT-STATE.md` and the S-type tests.
- **Row 76 (boundary gate).** `scripts/check-import-directions.mjs` encodes: browser graphs cannot import Node/server/test modules; `src/sources/*` and `layers/*/source.js` cannot import application/rendering/Cesium/browser globals; provider modules cannot import application/rendering modules. This is the same rule set WORLDVIEW states and should be re-implemented as a lint gate on day one.
- **Row 86 (ODbL).** Commercial use is permitted; the share-alike obligation attaches to the _derived database_ if it is publicly distributed in modified form, not to WORLDVIEW code. Keep the "© OpenStreetMap contributors" notice and the dataset README.
- **Esri World Imagery (row 7).** DATA_SOURCES.md notes "an app at scale should review current ArcGIS Location Platform terms". Mark as verify before commercial release; PMTiles-hosted imagery is the intended WORLDVIEW default.
