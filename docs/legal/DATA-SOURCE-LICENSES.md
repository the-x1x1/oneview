# WORLDVIEW — Data-source licence inventory

Status: **draft for legal review** · Generated 2026-09-21 · Machine-readable twin: [`config/licenses/providers.json`](../../config/licenses/providers.json) (schema `worldview/licenses/providers/v1`, 54 records)

Every data source GEV uses (from its `DATA_SOURCES.md` at commit `0dbde1e3`) plus every planned WORLDVIEW default is recorded here with its licence, its **data-use policy** (what the app may cache, retain, pack, export, redistribute) and a commercial-review verdict. `providers.json` is the file the app will actually read: provider-runtime, history-store, worldpack builder and the export service each enforce a field of `dataPolicy` (see §5).

## 1. How to read `dataPolicy`

| Field                                    | Meaning (as the app enforces it)                                                                                                                                   |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `cacheAllowed`                           | Transient on-disk/in-memory cache to avoid re-fetching (HTTP-cache semantics).                                                                                     |
| `rawPayloadRetentionAllowed`             | The provider's original payload may be written to history-store.                                                                                                   |
| `normalizedRetentionAllowed`             | WORLDVIEW `Observation` records derived from the payload may be written to history-store.                                                                          |
| `maxRetentionSeconds`                    | Hard cap the history-store applies to that provider's rows (absent = no provider-imposed cap; the user's own retention setting still applies).                     |
| `redistributionAllowed`                  | Data may appear in something WORLDVIEW hands to _other people_: a shared worldpack, a published export, a support bundle.                                          |
| `offlinePackAllowed`                     | Data may be baked into a worldpack built on and for the _same_ machine/user. (Sharing that pack is `redistributionAllowed`.)                                       |
| `exportAllowed`                          | The user may export observations from this provider (CSV/GeoJSON/report) with attribution stamped on.                                                              |
| `commercialUseAllowed`                   | `true` / `false` / `"conditional"` (allowed under conditions a human must accept) / `"unknown"` (no licence text found — treated as _not allowed_ until reviewed). |
| `attributionRequired`, `attributionText` | Attribution the UI must render whenever the provider's data is visible, and stamp onto exports.                                                                    |

Conservative defaults applied throughout: `"unknown"` ⇒ `commercialReview: manual-review-required`, `offlinePackAllowed: false`, `redistributionAllowed: false`. The generator in this workstream refuses to emit a record that breaks that rule.

**CCTV frame rule (global, not per-provider).** For every CCTV provider the `dataPolicy` describes the camera _catalog_ (positions, names, feed URLs). Camera _frames_ are governed by one product rule inherited from GEV (`DATA_SOURCES.md` line 78, lines 72-77): frames are fetched live from server-registered URLs, displayed, hashed at 64×36 to detect change, and **never written to disk, retained in history-store, exported, or redistributed**, whatever the pack's licence. This is a privacy boundary as much as a licence one (frames contain people and plates).

## 4. ODbL share-alike, stated once

Several defaults are OSM-derived (adsb.lol, Overpass, Photon/Nominatim results, OpenFreeMap tiles, Protomaps builds, datacenters, dams). ODbL 1.0 §4.4 share-alike attaches to a **derived database that is publicly used/conveyed**, not to WORLDVIEW's code and not to _produced works_ (rendered maps, screenshots). Practical consequences the product must respect (GEV states the same at `DS:141-143`):

- User-local history-store and user-local worldpacks are not public conveyance.
- A worldpack or history export **shared to another party** that contains OSM-derived rows is a conveyed derived database → it must carry the ODbL notice and be offered under ODbL. The worldpack builder therefore embeds `LICENSES.txt` listing every provider in the pack, and refuses providers with `redistributionAllowed: false` when the pack is marked shareable.
- Mixing ODbL data with proprietary data in one exported database (e.g. adsb.lol + TomTom) is exactly the collision ODbL warns about; the export service keeps datasets in separate tables/files with separate notices.

## 5. What the app enforces from this file

| Rule                                                      | Enforced by                                                                                        | Field                                                                |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| No raw payload persistence where prohibited               | history-store write path                                                                           | `rawPayloadRetentionAllowed`                                         |
| No normalized persistence where prohibited; cap retention | history-store write path + janitor                                                                 | `normalizedRetentionAllowed`, `maxRetentionSeconds`                  |
| No worldpack inclusion where prohibited                   | worldpack builder                                                                                  | `offlinePackAllowed` (local), `redistributionAllowed` (shareable)    |
| No export where prohibited                                | export service                                                                                     | `exportAllowed`                                                      |
| Attribution always visible and stamped on exports         | render-core attribution model → Cesium credit display / MapLibre AttributionControl; export writer | `attributionRequired`, `attributionText`                             |
| Provider not offered in the default build                 | provider registry at startup                                                                       | `plannedStatus` ∈ {excluded, deferred}; `commercialReview: excluded` |
| Provider gated behind a human decision                    | settings UI shows the condition text before enabling                                               | `commercialReview: conditional` / `manual-review-required`           |
| CCTV frames never persisted/exported                      | providers/cctv-public media path                                                                   | global rule (§1)                                                     |
| Google content never persisted                            | history-store denylist on `provider` prefix                                                        | google-maps-platform record                                          |

A unit test in `tools/` should load `providers.json` and assert the conservative invariants (`unknown ⇒ manual-review-required ∧ ¬offlinePack ∧ ¬redistribution`), so a future edit cannot silently loosen a policy.
