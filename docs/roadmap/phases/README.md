# Phase briefs

One file per phase, read with [../PARALLEL-PHASES.md](../PARALLEL-PHASES.md) (the rules
every phase follows) and [../INTEGRATION.md](../INTEGRATION.md) (what happens after).
`ownership.json` is the machine-readable list of what each phase may change;
`changelog/` holds each phase's CHANGELOG fragment until the integrator merges it.

Every brief has the same sections: status line, goal, read first, scope, deliverables,
definition of done, design notes (the harvested knowledge and the edge cases), amendment
requests (filled in by the phase as it finds them), evidence (filled in at the end).
